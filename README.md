# 🌙 Leyendas Mexicanas - Un Repositorio Digital de Terror

**Leyendas Mexicanas** es un sitio web informativo y accesible que funciona como punto de referencia para conocer y aprender sobre las leyendas de terror más populares de México. Este proyecto tiene como objetivo preservar, difundir y dar vida al rico folclore nacional a través de un entorno digital atractivo y fácil de usar.

## 🎯 Objetivo General

Crear un sitio web que sirva como una plataforma digital para consultar leyendas mexicanas de terror, enriquecido con contenido multimedia e información cultural relevante.

## 🧑‍🤝‍🧑 Público Objetivo

- Amantes de las historias de miedo y el terror.
- Estudiantes e investigadores de cultura y folclore.
- Público en general interesado en las tradiciones mexicanas.

## 🛠 Características Principales

### 📚 Base de Datos de Leyendas
- Recopilación de leyendas tradicionales mexicanas.
- Presentación clara y concisa de cada historia.
- En constante crecimiento y mejora.

### 🧭 Diseño Intuitivo
- Interfaz atractiva y sencilla de navegar.
- Menú claro y estructura lógica para facilitar la exploración.

### 📝 Información Detallada
- Descripciones completas de cada leyenda.
- Origen, variantes regionales y elementos culturales.

### 🎧 Contenido Multimedia
- Imágenes, audios y videos para enriquecer la lectura.
- Experiencia inmersiva e interactiva para el usuario.

### 🔄 Actualizaciones Periódicas
- Publicación regular de nuevas leyendas y contenido adicional.
- Espacio abierto a contribuciones de la comunidad.

## 💻 Tecnologías Utilizadas

- **HTML**: Estructura semántica del contenido.
- **CSS**: Estilos visuales atractivos y coherentes.
- **JavaScript**: Funcionalidad e interactividad, incluyendo:
  - Expansión de secciones
  - Reproducción de audio
  - Buscador de leyendas

## 🚀 Potencial de Crecimiento

- 🤝 **Colaboraciones**: Trabajo conjunto con escritores, investigadores y artistas.
- 🌐 **Traducciones**: Versión multilingüe para llegar a un público internacional.
- 🧩 **Actividades Interactivas**: Juegos, quizzes y recursos educativos.
- 🛍 **Tienda en Línea**: Productos temáticos como libros, camisetas y recuerdos.

## 🧙‍♀️ En Resumen

Este proyecto busca ser un **espacio digital donde los amantes del folclore mexicano** puedan sumergirse en un mundo de misterio, cultura y tradición. Basado en tecnologías web accesibles y con un enfoque en el usuario, **Leyendas Mexicanas** es una plataforma pensada para crecer junto a su comunidad.
